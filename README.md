# 올림픽공원 혼잡도 예측 - 데이터 수집

## 1. 인증키 넣기 (처음 한 번)

터미널에서:

```
cd ~/Desktop/"(주)한국체육산업개발 공모전"
cp env_template.txt .env
open -e .env
```

텍스트 편집기가 열리면 각 줄 `=` 뒤의 한글을 지우고 인증키를 붙여넣은 뒤 저장(⌘S)하세요.
`.env`는 숨김 파일이라 Finder에서 안 보이면 ⌘ + Shift + . 을 누르면 보여요.

## 2. 한 번만 받는 데이터

```
python3 fetch_static.py
```

| 단계 | 내용 | 저장 파일 |
|---|---|---|
| holidays | 2025~2026 공휴일 | data/holidays.csv |
| weather | 2025 서울 시간별 날씨 (ASOS 108) | data/weather_asos_108_2025.csv |
| linked | 2025 입출차·공연·날씨 연계 데이터 | data/linked_2025.csv |
| perf | 한국체육산업개발 공연정보 | data/performances_ksponco.csv |
| inout | 2025 입출차 원본 (수백만 건, 오래 걸림) | data/inout_2025.csv |

하나만 다시 받으려면 `python3 fetch_static.py weather` 처럼 이름을 붙이면 돼요.
입출차 원본은 Ctrl+C로 멈춰도 다시 실행하면 이어서 받아요.

## 3. 실시간 수집 (계속 켜두기)

새 터미널 창에서:

```
cd ~/Desktop/"(주)한국체육산업개발 공모전"
caffeinate -i python3 collect_citydata.py
```

5분마다 data/citydata/ 에 쌓여요. 맥북이 켜져 있고 이 창이 열려 있는 동안만 수집돼요.

## 4. 실시간 지하철 (공연 날 저녁에)

`.env`에 `SEOUL_SUBWAY_KEY=키` 한 줄을 넣고 `4_지하철수집.command`를 더블클릭하세요.
올림픽공원역, 몽촌토성역, 한성백제역 도착정보를 2분마다 data/subway/ 에 쌓아요.
하루 1,000번 한도가 있어서 1시간에 90번씩, 하루 약 10시간까지만 모을 수 있어요.

## 5. 실시간 주차 (계속 켜두기)

`5_주차수집.command`를 더블클릭하세요. 신청이나 키가 필요 없어요.
올림픽공원 동2문, 남2문, 북2문 주차장을 합친 지금 주차 대수를 10분마다 data/parking/ 에 쌓아요.
장기 주차 차량이 섞여 있어서 새벽에도 수백~천 대가 남아요. 그 바닥값을 빼고 봐야 해요.

## 6. 버스·지하철 하루 승하차 인원 (한 번씩)

`6_승하차받기.command`를 더블클릭하세요. 이미 쓰는 SEOUL_KEY로 돼요.
올림픽공원 주변 버스 정류장과 지하철 3개 역의 최근 40일 하루 승하차를 받아서,
공연 날 늘어난 사람 중 버스로 온 비중을 보여줘요. 데이터는 3일 늦게 올라와요.
처음에 찾은 정류장 목록은 data/ridership/stops.csv에 있어요. 엉뚱한 정류장이 섞였으면 그 줄을 지우고 다시 돌리면 돼요.

## 7. 버스 실시간·환승경로·주차장 정보 API 점검 (신청 뒤 한 번)

공공데이터포털에서 아래 3개를 활용신청(자동 승인)한 뒤 `7_버스API_점검.command`를 더블클릭하세요.
키는 기존 DATA_GO_KR_KEY를 그대로 써요.
- 서울특별시_정류소정보조회 서비스 (15000303)
- 서울특별시_대중교통환승경로 조회 서비스
- 한국교통안전공단_주차정보 (15099883)
- 국토교통부_정류장별 노선별 이용량 (15142065) — 하남 버스 같은 경기 버스 승객도 잡히는지 확인

## 8. 2025 입출차 1년치 (한 번, 1~2시간)

공공데이터포털에서 내려받은 입출차 파일과 연계 데이터 파일은 둘 다 딱 10만 줄에서 잘려 있어요(2025-11-03 ~ 12-07만 들어 있음).
`8_입출차_1년치.command`를 더블클릭하면 API로 1년치를 받아요. 끊겨도 다시 누르면 이어받아요.
- data/linked_2025.csv: 시간대별 주차대수, 방문객, 날씨, 공연명, 관람객 수
- data/inout_2025.csv: 차량 한 대씩 입차·출차 시각과 문

## 9. 입출차 1년치 빠르게 (8번 대신)

8번은 한 페이지씩 받아서 10시간 넘게 걸려요. `8_입출차_1년치` 창을 Ctrl+C로 멈춘 뒤 `9_입출차_빠르게.command`를 더블클릭하면,
8번이 받은 앞부분은 그대로 두고 남은 페이지를 동시에 4개씩 받아요. 요청 간격은 2.5초 이상으로 서버 규칙을 지켜요.
끝나면 data/inout_2025.csv 하나로 합쳐요.
